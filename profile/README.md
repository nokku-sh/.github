# Nokku

Short-lived SSH certificates for your servers, with plain OpenSSH on the client.

- [nk](https://github.com/nokku-sh/nk) is the CLI. It signs you in and keeps your certificates fresh.
- [nokkud](https://github.com/nokku-sh/nokkud) is the daemon for your servers. It renews host certificates and enforces access policies.
- [mon](https://github.com/nokku-sh/mon) holds the security primitives both share.
- [protos](https://github.com/nokku-sh/protos) is the API schema.

Found a vulnerability? Please use private vulnerability reporting in the Security tab of the affected repo.
